# Configure Telegram Channel

To receive notifications on Telegram, follow the steps below:

1. Open **Telegram** and start a chat with **[beepittbot](https://link)**.
2. Send the `/start` command to the bot.
3. When prompted, send your **Identifier Key**.

Once the key is verified, you’ll receive a confirmation message:  
**“Telegram account linked.”**

After setup, every time an incident occurs in your application, you’ll receive a notification on the same Telegram account used during setup.
