# Get the Identifier Key

Obtain your **Identifier Key** from [here](https://link).

The Identifier Key is a **UUID** and looks something like this:

```txt
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

Now we will connect various notification channels using the `Identifier key`, this key is used to connect and manage your notification channels. Make sure to keep it secure, as it uniquely identifies your setup.
