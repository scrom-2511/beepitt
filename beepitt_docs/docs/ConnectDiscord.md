# Configure Discord Channel

To receive notifications on Discord, follow the steps below:

1. Open **Discord** and start a chat with **[beepittbot](https://link)**.
2. Send the `start` command to the bot.
3. When prompted, send your **Identifier Key**.

Once the key is verified, you’ll receive a confirmation message:  
**“Discord account linked.”**

After setup, every time an incident occurs in your application, you’ll receive a notification on the same Discord account used during setup.
